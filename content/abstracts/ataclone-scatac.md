### Abstract

Single-cell analyses of cancer typically begin by identifying distinct populations of cancer cells by unsupervised clustering. However, in many cases this clustering is explained simply by differences in the copy number. To detect and estimate these differences in copy number, we have developed ATAClone. Applicable to both standalone and multiome scATAC-seq assays, ATAClone first identifies cancer ‘clones’ with shared copy number profiles, then estimates the copy number of each clone jointly. Advantages over other single-cell copy number calling tools include automated clone identification as well as ploidy-aware copy number estimation. In this workshop, participants will be guided step-by-step through a typical ATAClone workflow including key considerations at each analysis stage, as well as examples of downstream analyses using ATAClone outputs.
